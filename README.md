# VIVET — coffee shop website

Open `index.html` in your browser, or open this folder in VS Code and run Live Server.

Features: responsive purple-and-white layout, 12 demo menu products, category filters, image-rich category and promotional sections, shopping bag with local storage, mobile navigation.

Photos load from Unsplash and require internet. Product photos are illustrative and may not exactly match product names. This is a demonstration site: there are no actual orders, payments, rewards accounts or locations.

## Publish online with GitHub Pages
1. Create a public GitHub repository named `vivet`.
2. Upload the files inside this folder (index.html, style.css, script.js and optional README.md) to the repository root.
3. In repository Settings > Pages, choose Deploy from a branch, `main`, `/ (root)`, and Save.
4. Once published, the address is `https://YOUR-USERNAME.github.io/vivet/`.
